# shanghai-trip

This repository holds the travel plan for our team's conference trip from Beijing to Shanghai.

## What this repo is for

- Store and review the shared travel itinerary (see `itinerary.md`)
- Track the candidate train options, costs and the recommended option
- Keep booking/expense details (traveler count, budget, expense card checksum) in one place so the whole team can review before we book

**Trip:** Beijing South (北京南) → Shanghai Hongqiao (上海虹桥), Friday 2026-10-30, high-speed (G) trains only.
**Team size:** 4 travelers, second-class seats, sitting together.
**Budget:** CNY 700 per traveler (CNY 2800 total).

All bookings and changes go through the repository owner (see `CONTACTS.md`).
